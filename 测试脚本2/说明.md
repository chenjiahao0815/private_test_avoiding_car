# 靠右行驶期间无动车退出测试

使用 `地图/capella_map.yaml` 和 `capella_map.png`；可视化使用 `容器/避车测试.rviz`（复制自测试脚本的同名配置）。原来的 `地图/nav2.rviz` 保留，不再用于启动。保持原图像素、分辨率及原点不变，从自由区域选择通道。Nav2 使用原图的 StaticLayer；运动学仿真根据 /cmd_vel 积分位姿并发布 TF/里程计，本测试不验证实体碰撞。

## 运行

```bash
cd /home/linux/vehicle_total/tests/private_test_avoiding_car/测试脚本2
bash 运行场景.sh
# 已编译当前源码时：
bash 运行场景.sh --no-build
```

默认使用容器 `capella-ros-core-1`，可通过 `AVOID_TEST_CONTAINER` 指定其他已有兼容环境。使用独立工作区 `/root/avoid_scene2_ws`、ROS 域 194。运行结束自动清理本轮进程。日志默认在 `/tmp/avoid_test2_logs`，可通过 `AVOID_TEST_LOG_DIR` 修改。

## 验证范围

分别加载仓库中的两棵完整行为树，不修改它们的 XML：

- `garage_vehicle_avoidance.xml`
- `garage_vehicle_avoidance_dual_side.xml`

每棵树分别测试动车消失后持续发送空数组、完全停止发送 `/car_information`，共四轮。

每轮先执行正常 Nav2 任务，暂停后启动避车。可控找点服务先返回“未找到”，让树进入靠右分支；检测到实际靠右位移后，再让后续找点 Action 保持 RUNNING，直至收到取消。先丢车 1 秒再恢复 1 秒，确认没有提前退出，随后持续无车，检查：

1. 距离最后一条非空车辆消息约 3 秒后，避车返回成功（容许采样及取消开销：2.9～4.5 秒 ROS 时间；本测试采用墙钟）。
2. 未完成的找点 Action 确实收到取消，而非等找点自行结束。
3. 确认取消后下发并保持零速度指令，测试上位机重新下发先前的原任务目标，Nav2 成功到达。

行为树、靠右路径服务、Nav2 都是真实程序；底盘运动采用容器已有的 fake_sensor_publisher。找点服务是专用测试替身，用来稳定制造“未返回的找点请求”；这不是对真实找点算法的验证。恢复原任务由测试上位机执行，行为树本身负责结束避车并返回成功。

原图完整加载，global costmap 使用 60×60 米滚动窗口，避免反复传输约 3300 万个原图栅格。报告包含用例、计时、找点及 FollowPath 取消事件、实际轨迹和 /cmd_vel 记录。专用启动副本使用运动学仿真定位，不启动 AMCL，不修改容器正式启动文件。
